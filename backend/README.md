# backend/ — 后端源码

> 后端项目原样落位在此，**内部结构跟随实际技术栈与框架，本骨架不做规定**。

## 使用方式

* **引入开源框架**（pig / yudao 等）：源码直接放入本目录（或保留框架自带的多模块布局），不强行改组。

* **自研项目**：自由组织；建议至少留一个 README 说明分层与模块边界。

## 约定

* 框架中「不可修改」的核心 / 基座模块遵循**禁改源码、只用能力**（见 [AGENTS.md §2](../AGENTS.md)）。

* 业务定制改动尽量集中、保持可升级，并在 [docs/plan](../docs/plan/README.md) 变更记录中登记。

* 构建与启动命令唯一维护处在 [AGENTS.md §6](../AGENTS.md)，此处不复制。

* 数据库脚本统一放仓库根 [sql/](../sql/README.md)，由用户执行，不自动跑。
