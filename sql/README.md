# sql/ — 数据库脚本

> 开发期**增量脚本的唯一维护处**。**执行前备份数据库。**

---

## 命名与编号

| 规则 | 说明 |
|------|------|
| 文件名 | `NN_用途描述.sql`，NN 两位编号全局递增，**只增不改已发布脚本** |
| 一事一号 | 一个脚本只做一件事（建表 / 加字段 / 权限 / 数据修复），文件名说清用途 |
| 环境 | 同一用途多环境差异时用后缀区分（如 `13_xxx_local.sql` / `13_xxx_docker.sql`） |

---

## 执行约定

- **由用户在数据库执行后告知「已执行」**，AI / 脚本不自动跑。
- 推荐执行顺序维护在本文件：新环境一条链、存量库增量链，分开写。
- 脚本尽量**幂等**（可重复执行不报错）。
- 业务表脚本按需初始化测试账号与字典 / 菜单 / 权限数据。

---

## 与发布 SQL 的分工

| 位置 | 角色 |
|------|------|
| 本目录 sql/ | 开发期增量脚本，编号递增 |
| deploy/ 下（如 `deploy/sql/`，按需创建） | 发布用合并脚本：全量（新环境一次导）+ 版本增量（存量库升级） |
