# api/ — 前后端接口契约

> 前后端对齐的**唯一契约源**。联调争议、字段命名、错误码都以此为准。

## 放什么

| 内容 | 形式 |
|------|------|
| 接口清单与字段定义 | OpenAPI / Swagger 导出产物，或结构化 Markdown |
| 错误码登记表 | 错误码 → 含义 → 前端处理建议，全局唯一维护处 |
| 通用横切约定 | 认证方式、加密约定、分页 / 排序参数、时间与金额格式 |
| 契约变更记录 | 变更日期、影响面、是否破坏兼容 |

## 约定

- **契约先行**：接口新增 / 变更先改本目录再动代码。
- 前端按契约**并行开发与 mock**，不等后端实现；后端实现完成后以契约为验收口径。
- 字段命名前后端一致，不手工转义；日期、金额、分页等格式全局统一一次。
- 后端可从代码导出 OpenAPI 产物提交到本目录，与手写说明互补；导出产物不手改。
- 错误码与后端异常枚举一一对应，改一边必须同步另一边。
- 破坏性契约变更（删字段、改语义）：先在变更记录标注，给前端一个迭代的缓冲期。

## 纯后端服务注意

无前端消费方的服务（对接第三方、纯 API 产品），本目录退化为对外 API 文档；仍保留错误码表与变更记录。
