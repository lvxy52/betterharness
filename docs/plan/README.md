# plan/ — 开发计划与验收指南

> **进度、勾选、变更记录只在本目录维护。** 维护者：开发；消费者：开发、联调、PM。

## 文件约定

| 文件 | 角色 |
|------|------|
| `DEVELOPMENT_PLAN.md` | 首版（V1.0）开发计划，完成即**封版**不再改 |
| `DEVELOPMENT_PLAN_V{N}.{M}.md` | 每轮迭代一份：按编号推进，完成打 `[x]`，附变更记录 |
| `ACCEPTANCE_GUIDE.md` | **验收指南（联调唯一参考）**：测试账号、权限模型、SQL 习惯、端到端验收步骤 |

## 开发计划写法约定

- 按模块编号推进；每项含：做什么（**用具体描述，不贴代码 / UI 码**）、SQL 依赖、验收口径。
- 变更记录只登记**最终方案**，不记录中间失败尝试；日志标题写丰富，一眼看懂改了什么。
- SQL 依赖项标注「用户执行后告知」，不自动跑。

## 验收指南写法约定

- 账号表（角色 × 账号 × 密码 × 菜单范围）**唯此一处维护**，其它文档只链接。
- 数据权限模型用文字 + 表格说清判定规则；两层以上独立权限分别说明并标注「不要套用」。
- 记录环境习惯（SQL 执行方式、重启约定、登录加密方式、常见坑）。
