# docs/ — 项目文档

> **文档总入口。** 子类目按需增减，每类一个 README 作详细索引。

## 目录索引

| 子目录 | 管什么 | 维护原则 |
|--------|--------|----------|
| [prd/](./prd/README.md) | 产品需求：字段、菜单、流程 | 基线冻结 + 迭代增量；先改文档再改代码 |
| [api/](./api/README.md) | 前后端接口契约：字段、错误码 | 契约先行 |
| [plan/](./plan/README.md) | 开发计划、进度、变更记录、验收指南 | **进度与测试账号只在此维护** |
| [rules/](./rules/README.md) | 编码规范与自测清单 | 强制约束，写代码前必读 |

## 维护规则

- 使用开源框架时，接口契约可部分由框架自带文档（Swagger 等）承担，本目录只留**增量契约与业务约定**。
- **单一维护原则**：进度只在 plan/、需求只在 prd/、规范只在 rules/，其它位置只链接。
- 需要新类目（设计资产、架构决策、复盘等）时直接增设，并在上表登记。
- 不在 docs/ 放编译产物、日志、临时截图。
