# prd/ — 产品需求

> 业务需求的**唯一权威来源**。维护者：产品；消费者：开发、测试、UI。

## 文件约定

| 文件 | 角色 |
|------|------|
| `PRD_clean.txt` | **主文档**：纯文本，便于检索与 diff |
| `PRD_clean_V{N}.{M}.txt` | 迭代增量文档：每轮迭代一份，只写变更 |
| `*.docx` | 会议评审与归档的 Word 版 |
| `*.bak.YYYYMMDD` | 文本快照，归档不删 |

## 约定

- 字段 / 菜单 / 流程变动**先改 PRD 再改代码**。
- 基线版（V1.0）完成后冻结，只作参照；当前迭代以增量文档为准。
- 开发计划、规范、验收指南只**链接** PRD，不复制字段定义。
- 角色 / 权限定义以 PRD 为准（如「仅客服可导入」），测试用例照此设计。
